Shift 原生宿主对照 v3（macOS ARM，独立实验应用）

1. 把两个 app 拖到本地文件夹，分别打开。它们不是 OpenIDEA 修复版。
2. 先切到搜狗。在 AppKit 应用选择“搜狗中文”或“搜狗英文”（按实际状态手动选择）。
3. 保持高级探针不勾选，点击“开始并聚焦输入框”，左 Shift 按一下松开，右 Shift 按一下松开。无需打字。
4. 点“停止并导出 JSON”，选本地保存位置。
5. 在 Tauri 应用中以相同输入法状态重复上述操作。先把这两份 JSON 发回即可。

高级回调探针仅供进一步定位：需要时勾选后再重复一轮。它会临时包装本进程的输入上下文方法，可能影响时序；因此应先保留关闭时的对照。
不支持时界面和 JSON 会显示 unavailable；没有回调的调用记 pending，不代表 handled=false。
Shift 本身可能切换搜狗中英文，开始前请留意实际模式。程序不自动识别或修改输入法。

数据与边界：默认不采集；只观察本应用窗口。最多6000条内存记录，达到上限自动停止；关闭窗口停止。没有自动上传。
记录 Shift、安全状态、文字长度、手动标签、版本与宿主信息；不记录实际输入文字、剪贴板、命令或个人路径。JSON 是明文。
两款应用的 bundle ID 不同，这是实验潜在混杂；它们没有冒充 Safari 或原 OpenIDEA。
HTML 内容完全相同、哈希随导出提供；页面与原生使用不同单调时钟，关联是时序推断。
未签发 Developer ID、未公证，使用 ad-hoc 签名；如果系统不允许打开，可通过系统“隐私与安全性”确认来源后允许。无需关闭 SIP，也不需要辅助功能权限。
自动化检查覆盖合成事件和回调语义，不代表真实搜狗验证通过。
